How to Use LLM-Assisted Annotation
  1. Review LLM suggestions highlighted with solid borders in the text below
  2. Click approve (✓) or reject (✗) for each LLM suggestion
  3. Correct rejected entities: After rejecting, select a larger or corrected span and it will replace the rejected entity
  4. Add manual annotations by selecting plain text and choosing an entity type - these will appear with dashed borders
  5. Save your decisions for analysis and final annotation
Note: LLM suggestions have solid borders, manual annotations have dashed borders. Manual annotations will replace rejected LLM suggestions if they overlap.
